### Hi, I'm Daniel

Infrastructure and platform engineer in the Bay Area. I build Kubernetes-native control planes, database infrastructure, and the observability and on-call tooling around them.

**What I've built**
- A Kubernetes operator that manages nearly 200 production PostgreSQL (Aurora) clusters, replacing a ticket-based provisioning workflow with self-service.
- A connection-pooler controller that keeps 100+ services under Aurora's connection limit, and the migration of those services from PgBouncer to PgCat.
- Fleet-wide PostgreSQL observability with Prometheus, from fleet level down to table level.
- Agent workflows with MCP, structured output and tracing for cost, latency and output quality.
